# Verification log

What has been tested on this server, against your own community, and when. Newest first.

Why keep this: Skool changes without notice, and "it worked once" fades fast. This file is how a future session (yours
or an AI agent's) knows what is proven and what is assumed. Record what was actually exercised, how, and the result,
including what was *not* tested.

The template itself was verified before release, by running this code against a live community: every read tool, the
health check with one and two accounts, the nightly course-progress collection, and comment paging. That says the code
works. It says nothing about your deployment, which is what this log is for.

## Template

Copy this for each entry:

```
### YYYY-MM-DD: <what changed or was tested>
- Tested: <tools / checks exercised, and how: AI app chat, smoke script, health check>
- Result: <pass / fail, with the numbers that prove it, e.g. "health check 26/26 ok">
- Not tested: <anything left unproven>
```
